# Contributing

Report bugs in [Issues](https://github.com/RustyNovoBland77464/scmdraft-fan-addon/issues) with steps to reproduce, a screenshot and your OS/Wine version. For mining issues, include the map, race and boost settings.

For code changes, follow [BUILDING.md](BUILDING.md) and open a pull request explaining what changed and how you tested it.

Please don't include StarCraft assets or the original ScmDraft executable.
