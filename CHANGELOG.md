# Changelog

## 0.1.0 — private preview

Initial community extension package: HD terrain/units/sprites, additional terrain symmetry and
copy tools, real collision-box overlays, animated mining tests, timed resumable boost searches,
per-worker command guides and faster mining playback. Adds standalone builds and installation tooling.

Original ScmDraft and StarCraft assets remain separately supplied by users.

The Windows setup executable now embeds the plugin, mining tool and dependency notices; it can be downloaded and run on its own.
