# Changelog

## 0.1.2 — private preview

- Fix return-cargo and cycle searches rejecting faster mining cycles when the walking distance stays the same or increases slightly.
- Verify the Protoss end-patch boost on both left spawns of Attitude and Octagon: 150-frame cycles in independent long runs.

## 0.1.1 — private preview

Renamed to ScmDraft Fan Add-on. All add-on commands now live in the New menu, with shortcuts for mining, mirrored copy, unit-sprite replacement and hitboxes. Building and unit hitboxes start off on every launch.

## 0.1.0 — private preview

Initial community extension package: HD terrain/units/sprites, additional terrain symmetry and
copy tools, real collision-box overlays, animated mining tests, timed resumable boost searches,
per-worker command guides and faster mining playback. Adds standalone builds and installation tooling.

Original ScmDraft and StarCraft assets remain separately supplied by users.

The Windows setup executable now embeds the plugin, mining tool and dependency notices; it can be downloaded and run on its own.
